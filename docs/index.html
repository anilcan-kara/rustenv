🔐 rustenv
GitHub →

Secret & .env management,
written in Rust.

Show with masked values, diff environments side-by-side, validate syntax, export to Docker/JSON/Shell, and AES-256 encrypt for Git storage.

cargo install rustenv

👁️ Secret Masking

Auto-detects sensitive keys (SECRET, TOKEN, PASS) and masks them in terminal output.

🔍 Environment Diffing

Compare two .env files side-by-side to catch missing keys between staging and production.

🔐 AES-256 Encryption

Encrypt .env files into .env.enc using AES-256-GCM for safe version control storage.

📤 4 Export Formats

Export environment variables to Shell scripts, Docker --env flags, or structured JSON.
